CLUTCH BAGS KENYA — local website (no PHP, no server)
=====================================================

HOW TO OPEN
  Unzip the folder and double-click  index.html  (Chrome, Edge, Firefox or Safari).
  Keep the folders (css, js, img) next to index.html.

ADMIN PANEL
  Open  index.html#/admin   (or click "Admin" in the footer)
  Default password: admin123   -> change it in Admin > Settings.
  Manage: products (photos, colours, specifications, prices, stock), categories,
  home banners, orders, messages, store settings, promo code and sale countdown.

WHAT'S NEW IN THIS VERSION
  * Full-width home banners (left side faded, title and offer on top), 9 different slides
  * Pop-up welcome offer, quick-view pop-ups, cart drawer, photo lightbox
  * Animated sections, flash-sale countdown, trending tabs, occasion / budget shortcuts
  * Big product page: large photos (auto-slide every 5.5 s), icon key facts,
    specifications, delivery checker, share buttons, related + recently viewed
  * 108 clutches in 8 categories
  * Pages: Offers, About, Delivery & Returns, FAQ, Track order, Privacy, Terms, Wishlist
  * Every button and link opens something

IMPORTANT — PLEASE EDIT IN ADMIN > SETTINGS
  Phone, WhatsApp, email, address and M-Pesa details are PLACEHOLDERS. Replace them.
  Only the X/Twitter handle @clutch_bags_ke came from the old website.
  Check the promo code (WELCOME10), the sale title/end date and the returns,
  privacy and terms wording so they match your real policies.

ABOUT THE PRODUCTS
  The products are NOT copied from Jumia (their site does not allow automated
  copying). They are standard clutch styles with our own names, prices and drawn
  pictures. Replace them with your real stock and photos in Admin > Products.

WHERE DATA IS SAVED
  Products, orders and settings are saved in THIS browser (localStorage).
  Use Admin > Settings > Backup regularly. Clearing browser data erases the shop.
  To run the shop for real customers on other devices it must be hosted with a
  real database; this local version is for testing and previewing.
